# 🎓 College Fest 2026 - Event Website

## 📌 Project Description

College Fest 2026 is a simple and interactive college event website developed as a Git and GitHub Workshop Mini Project.

The website provides complete information about the event, including event details, schedule, speakers, registration, and contact information.

## ✨ Features

- 🏠 Home page
- 📋 About the Event
- 📅 Event Schedule
- 🎤 Speakers Information
- 📝 Online Event Registration
- 📞 Contact Information
- 📱 Responsive website design
- ✅ Registration success message

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 🌿 Git Branches Used

The project was developed using separate feature branches:

- `main` - Main project
- `schedule` - Event schedule feature
- `speakers` - Speakers feature
- `registration` - Registration feature
- `contact` - Contact feature

Each feature was developed in a separate branch, committed, pushed to GitHub, and merged into the `main` branch.
